# Contact Form App

A web application built with Node.js, Express, EJS, and MySQL.

## Description

A personal contact form application that allows visitors to submit their contact
information. Includes an admin page to view all submitted contacts. This has both client-side and server-side
validation, a portfolio page showcasing projects, and a resume page.

## Features
- Contact form with client-side and server-side validation
- MySQL database integration for storing submissions
- Admin page to view all contacts
- Portfolio page with project showcases
- Resume page
- Responsive layout for mobile

## Technologies Used

- Node.js
- Express
- EJS
- MySQL
- dotenv
- CSS
